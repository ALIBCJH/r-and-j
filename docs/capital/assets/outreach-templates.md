## Rules for all outreach

1. **Tailor the hook, always.** One specific, genuine reason you're contacting *them* beats any amount of polish.
2. **Short beats comprehensive.** First-touch ≤ 150 words. The goal is a call, not a decision.
3. **One honest traction line — never inflated.** (Narrative §5.)
4. **Always give an easy "no."** It builds the trust that converts the "maybe"s.
5. **Log every send in the [CRM](../05-crm-pipeline.md)** with date + next action.
