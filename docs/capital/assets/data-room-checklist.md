# Asset — Data Room Checklist

**R&J Interiors · Capital Brain / Assets**
Status: Working checklist · Version 1.0 · 2026-07-09
Owner: Startup CFO + Founders · Review cadence: Before any raise; keep evergreen

> **What this is.** The folder of everything a funder, lender, or program will ask for. Build **v1 once**, reuse everywhere, keep it current. A ready data room is the difference between a fast "yes" and a stalled conversation. Closing [`04-readiness-gaps.md`](../04-readiness-gaps.md) G5 = completing the ⭐ items below.
>
> **Privacy:** the data room contains sensitive material (financials, IDs, contracts). Share via a controlled link per counterparty; never post it publicly. Do not include live admin credentials or secrets.

---

## Tier 1 — Data room v1 (build now; needed for *any* serious conversation)

**Company & compliance** ⭐
- [ ] Certificate of registration / incorporation
- [ ] KRA PIN + tax-compliance certificate
- [ ] MSEA registration (via eCitizen) — *unlocks government funds & tenders*
- [ ] Founders' IDs / KYC basics
- [ ] Cap table (even if just the two founders) & any prior funding/loans
- [ ] Founders' agreement / equity split (if documented)

**The story & the product** ⭐
- [ ] One-pager ([`one-pager.md`](one-pager.md)) — exported, current
- [ ] Pitch deck (10–12 slides, from [`narrative-and-pitch-outline.md`](narrative-and-pitch-outline.md))
- [ ] Link/demo access to the live visualizer (rjinteriors.studio)
- [ ] 3–5 real product/room photos (proof of craft)

**The numbers** ⭐
- [ ] Simple financial model: revenue assumptions, costs, runway (12–24 mo)
- [ ] **Unit economics per order** — true gross margin after fabric, making-labour, consultation credit, delivery, install *(⚠️ blocked on G3 — export from KV; label "modelled" until measured)*
- [ ] Current cash position & monthly burn / runway *(blocked on G9)*
- [ ] Pricing sheet (reconciled — no homepage/catalog contradiction, G6)

**Demand evidence** ⭐
- [ ] Pre-launch campaign results: backers, KSh committed *(label honestly — "interest" not "traction" until the intent instrument, G2, is live)*
- [ ] Customer-interview summary *(blocked on G1 — 15–20 interviews)*

## Tier 3 — Debt / government-fund specific

- [ ] Bank / M-Pesa transaction statements (the trading-history key — G11)
- [ ] Collateral documentation (for KIE / secured facilities)
- [ ] Machinery/equipment quotes (for asset finance / Nyeri EDF tech line)

## Maintenance rules

1. **One canonical version** — a dated folder; supersede, don't fork.
2. **Refresh metrics before every send** — stale numbers read as careless.
3. **Honesty gate** — every figure is either measured (cite source) or labelled "modelled/assumption." Never launder an assumption into a fact.
4. **Tailor the top, reuse the rest** — swap the one-pager's ask and the deck's emphasis per audience; the underlying data stays constant.
